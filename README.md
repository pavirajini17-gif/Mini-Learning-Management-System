# 🎓 LearnHub – Mini Learning Management System

**LearnHub** is a web-based Mini Learning Management System (LMS) designed to make online learning simple, interactive, and accessible.

The platform allows students to explore available courses, enrol in courses, complete lessons, monitor their learning progress, participate in quizzes, and generate certificates after meeting course requirements.

## ✨ Features

- 👤 Student and Admin Login
- 📚 Course Catalog
- 📝 Course Enrolment
- 📖 Interactive Lessons
- 📊 Learning Progress Tracking
- 🧠 Interactive Quizzes
- 🌐 Open Trivia DB API Integration
- 🏆 Certificate Generation
- 💾 SQLite Database Storage
- 📱 Responsive User Interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **External API:** Open Trivia DB API

## 🎯 Project Objective

To develop a simple and user-friendly online learning platform where students can improve their skills, track their learning activities, test their knowledge, and achieve course completion certificates.
